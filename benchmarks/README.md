# 检索评测数据

- retrieval_cases.json：固定的 60 条问题、split、类别、正确片段 ID 与原文证据。
- dev_results.json：10 条开发问题的真实本地输出。
- ../docs/retrieval_results.json：50 条报告用测试问题的真实本地输出。
- ../docs/RETRIEVAL_OPTIMIZATION.md：设计、指标、实测结果与讲解线。

33 份虚构制度位于 app/sample_data/docs，当前各形成一个片段。
40 条有答案测试问题按 20 个主题各编写一个精确问法和一个口语改写；
10 条无答案问题单列。dev 有 8 个正例和 2 个无答案例。
问题和标签在首次运行向量模型之前写入；dev 验证方案后，沿用默认 RRF 参数。
这是人工编写的合成回归集，未经过独立审核；测试含已知故障问法，不是独立盲测。

加载时核验：问题与 ID 唯一、split 和类别合法、正例标签存在、原文包含证据。
无答案表示文档里没有直接支持问题的答案，不要求最近邻搜索返回空列表。
标签含糊之处保留原样并在分析文档披露，不根据测试结果删题或改标签。

每个正例目前只有一个相关片段。Recall@3 不以含无答案问题的总数为分母，
也不能把 3 个片段知识库里 Top 3 命中当作充分验证。
报告记录数据、源码与语料、模型文件摘要，以及环境和逐题结果。
预热后耗时包含查询 embedding，不含 HTTP、生成模型、下载和建库。

计时受机器和负载影响，不以固定毫秒值做 CI 断言。
默认单元测试使用确定性的测试编码器检查协议和缓存，不下载模型；
成绩报告由真实 BGE 模型生成，二者用途不同。
